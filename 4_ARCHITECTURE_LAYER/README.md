# 4. Architecture Layer

How the pieces are wired together, and how portable that wiring is.

**Keep here:** notes and isolated snippets about dependency injection,
layering (API / service / repository / infrastructure), unit-of-work and
repository patterns, authentication/authorization design, and the FastAPI vs
Litestar comparison — what's framework ergonomics vs what's genuine
architecture that should survive a framework swap.

**Not here:** the running capstone application itself — that lives in
`/capstone`. This folder is for understanding and reference material *about*
this layer, extracted from that work.

**Maps to curriculum weeks:** 5 (DI & application structure), 6 (auth), 17
(Litestar production patterns & framework evaluation).
