# 3. Performance Layer

Concurrency, throughput, and knowing where time actually goes.

**Keep here:** notes and isolated snippets about asyncio/ASGI concurrency,
blocking vs non-blocking I/O, load testing, profiling, connection pool
sizing, timeouts/retries/circuit breakers, and benchmark results (before/after
numbers, not vibes).

**Not here:** the running capstone application itself — that lives in
`/capstone`. This folder is for understanding and reference material *about*
this layer, extracted from that work.

**Maps to curriculum weeks:** 3 (async Python, ASGI, concurrency), 14
(performance and resilience).
