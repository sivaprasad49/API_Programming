# 1. API Layer

The HTTP/framework surface: how a client talks to the service.

**Keep here:** notes, small isolated snippets, and experiments about routing,
request/response handling, validation, serialization, status codes, headers,
OpenAPI generation, and framework-specific ergonomics (FastAPI, Litestar).
Anything you'd describe as "how the framework turns HTTP into Python and back."

**Not here:** the running capstone application itself — that lives in
`/capstone`. This folder is for understanding and reference material *about*
this layer, extracted from that work.

**Maps to curriculum weeks:** 1 (HTTP fundamentals), 4 (FastAPI routing &
validation), 7 (advanced API design), 16 (Litestar fundamentals).
